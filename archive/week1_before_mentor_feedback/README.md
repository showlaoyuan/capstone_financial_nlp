# Week 1 Prototype Archive

This folder contains Week 1 prototype files created before mentor feedback.

## Background

These archived files come from the early prototype stage of the project.
At that stage, the work focused on:

- FPB
- FiQA
- FinQA

The early work included:

- dataset download
- structure inspection
- unified CSV conversion
- small-scale training and test sample preparation
- synthetic QA sample preparation

After mentor feedback, the project direction was revised into a more rigorous 4-dataset Financial NLP evaluation workflow with around 5000 samples.

## Note

These archived files are kept for traceability.
They are not final experimental results.
