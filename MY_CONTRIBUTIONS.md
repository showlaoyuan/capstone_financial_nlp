# My Contributions

## My Role in the Original Project

In our team Financial NLP capstone project, I mainly worked on data processing and experiment execution. My responsibility was to prepare the datasets for evaluation, run the relevant experiments, and organize the outputs so that the results could be checked. Other parts of the team project, including model training and overall system design, were handled by other team members.

## Work Completed in This Repository

I reorganized the FPB, FiQA-SA, FinQA, and financial-mmlu-ko datasets and converted their different source structures into a consistent evaluation format. I checked missing values, duplicate records, labels, and required fields, then generated the smoke, pilot, and full evaluation files. I also cleaned up the run scripts, result files, and documentation needed to follow the data and evaluation workflow.

## Additional Model Comparison

I completed a prompt A/B test and used the better-performing prompt configuration for each model in the final comparison. DeepSeek V4 Pro and Solar Pro 3 were evaluated on the same fixed pilot set of 800 records. This comparison supplements the experiment work I was responsible for in the original capstone and gives that part of the project a clearer, more complete record.

## Contribution Boundaries

This file describes only the data preparation, evaluation setup, experiment execution, and result organization that I personally completed and later organized in this repository. It is not a summary of every contribution made by the original team.
