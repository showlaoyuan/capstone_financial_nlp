# Project Revision History

## Week 1 Prototype

The project initially started as a small-scale data preparation prototype.
The Week 1 workflow used about 200 samples per dataset to check whether the data pipeline worked as expected.

## Mentor Feedback

After mentor feedback, the project direction changed because around 200 samples per dataset were not enough for reliable experiment comparison.

## Revised Direction

The revised project direction is to expand to around 5000 samples and focus on a more rigorous 4-dataset Financial NLP evaluation workflow.

This revised direction emphasizes:

- data quality validation
- experiment input verification
- relabeling
- cross-checking
- experiment logs
- cost and latency tracking
- result organization

Before the revised PyCharm rerun, the old Week 1 prototype scripts were archived from `app/api/` into `archive/week1_before_mentor_feedback/app/api/` to reduce confusion between prototype code and the future revised workflow.

The revised 5000-sample dataset and final results will be added later after the pipeline is rerun in PyCharm and the outputs are verified.
